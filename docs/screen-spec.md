### S01 モード選択画面

| 項目 | 内容 |
|---|---|
| パス | `/` |
| モード | 起動 |
| デバイス | スマホ / タブレット / PC |
| 認証 | 不要 |

#### 概要
アプリ起動時の入口。毎回手動でモードを選択する。営業開始・終了・再開もここで操作する。

#### UI要素

| # | 要素 | 説明 |
|---|---|---|
| 1 | ホールモードボタン | 締め済み時はグレーアウト・タップ不可 |
| 2 | キッチンモードボタン | 締め済み時はグレーアウト・タップ不可 |
| 3 | 営業状態バッジ | 営業中 / 締め済み を色分け表示 |
| 4 | 営業開始日時 | 現在の営業セッション開始時刻を常駐表示 |
| 5 | 営業を締めるボタン | 確認モーダル → セッション確定 |
| 6 | 営業を再開するボタン | 締め後のみ表示。誤操作時の復帰用 |
| 7 | 新しい営業を開始するボタン | 締め後のみ表示 |
| 8 | 管理者リンク | 目立たせずに小さく配置 |

#### 備考
- 営業終了は確認モーダルを挟む
- 締め後はホール・キッチンボタンが無効化され「営業を開始してください」と表示

### S02 席一覧（ホール）

| 項目 | 内容 |
|---|---|
| パス | `/hall` |
| モード | ホール |
| デバイス | スマホ |
| 認証 | 不要 |

#### 概要
ホールモードのトップ。管理者が設定したレイアウトを読み取り専用で表示。空席を複数タップ選択しグループを作成する。

#### UI要素

| # | 要素 | 説明 |
|---|---|---|
| 1 | 席マス | 席名・ステータスを表示 |
| 2 | ステータスバッジ | 空席 / 使用中 / 提供待ち / お会計待ち |
| 3 | 複数選択 | 空席をタップで選択。「グループ作成」ボタン出現 |
| 4 | 人数入力モーダル | グループ作成時に人数を入力（選択席数でプリセット） |
| 5 | 提供待ちバッジ | 🍽 n件（黄色）で識別 |
| 6 | モード切替 | キッチンモードへの切替ボタン |
| 7 | 警告バナー | 営業終了予定時刻超過時にヘッダーへ赤色表示 |

#### ステータス定義

| ステータス | 色 | 説明 |
|---|---|---|
| 空席 | グレー | 未使用 |
| 使用中 | 濃グレー | グループ在席中 |
| 提供待ち | 黄 | 調理完了・未提供のアイテムあり |
| お会計待ち | オレンジ | お会計フラグが立っている |

### S03 キッチンダッシュボード

| 項目 | 内容 |
|---|---|
| パス | `/kitchen` |
| モード | キッチン |
| デバイス | タブレット / 大画面モニター |
| 認証 | 不要 |

#### 概要
キッチンの常設画面。未調理注文のみ全グループ横断で一枚絵として表示。リアルタイム自動更新。

#### UI要素

| # | 要素 | 説明 |
|---|---|---|
| 1 | 表示切替トグル | カード型 / チケット型 |
| 2 | 提供待ちエリア | 調理完了後のアイテム。「提供完了」ボタン付き |
| 3 | 【カード型】グループカード | グループ名 + 席名 + 未調理アイテム一覧 |
| 4 | 【チケット型】カンバンレーン | 大分類 → 小分類 → 横スクロールのチケット列 |
| 5 | 経過時間表示 | 経過時間（12分前）+ 注文時刻（21:15）を両方表示 |
| 6 | 調理完了ボタン | → 提供待ちエリアに移動 |
| 7 | 品切れ登録 | 即時メニューから非表示 |
| 8 | モード切替 | ホールモードへの切替ボタン |
| 9 | 警告バナー | 営業終了予定時刻超過時にヘッダーへ赤色表示 |

#### 時間カラー

| 経過時間 | 色 |
|---|---|
| 〜7分 | グレー（通常） |
| 8〜14分 | オレンジ（注意） |
| 15分以上 | 赤（警告） |

### S04 グループ詳細（共通）

| 項目 | 内容 |
|---|---|
| パス | `/hall/group/:id` `/kitchen/group/:id` |
| モード | 共通（ホール・キッチン両方から利用） |
| デバイス | スマホ: フルスクリーン / タブレット: サイドパネル |
| 認証 | 不要 |

#### 概要
ホール・キッチン共通の操作画面。グループに関するすべての操作をここで行う。

#### タブ構成

| タブ | 主な操作 |
|---|---|
| 注文履歴 | ステータス確認・調理完了・提供完了・キャンセル |
| メニュー | 店内 / テイクアウトトグル + カテゴリタブ + 個数指定で追加 |
| コース | コース選択 → 料理一括注文 + 飲み放題有効化 |

#### 注文ステータス操作

| ステータス | 操作ボタン | 遷移先 |
|---|---|---|
| 未調理 | 調理完了 | → 提供待ち |
| 提供待ち | 提供完了 | → 提供済み |
| 提供済み | — | （変更不可） |
| — | × ボタン | → キャンセルモーダル |

#### キャンセルフロー

```
× タップ
  ├── qty = 1 → 確認モーダル → キャンセル済みに
  └── qty ≥ 2 → 数量選択モーダル（1〜qty のボタン）
                → 選択数だけ減算
                → 残qty = 0 → キャンセル済みに
                → 残qty ≥ 1 → 数量が減った状態で継続
```

#### テイクアウト注文

- メニュータブの `[店内] / [テイクアウト]` トグルで切替
- テイクアウト選択時は `takeout: "both"` と `takeout: "takeout"` の商品のみ表示
- 注文履歴に `[TO] 商品名` で識別

#### コース適用

- 1グループに1コースまで
- コース選択 → 確認モーダル（含まれる料理 + 飲み放題プラン表示）→ 適用
- 料理 → 一括注文（一度きり）
- 飲み放題 → 適用中はプラン内ドリンクを何度でも注文可

#### ヘッダーボタン

| ボタン | 動作 |
|---|---|
| お会計 | 確認モーダル → お会計待ちフラグを立てる |
| 退店 | 確認モーダル → グループ解散・席を空きに戻す |

### S07 席レイアウト設定

| 項目 | 内容 |
|---|---|
| パス | `/admin/seats` |
| モード | 管理者 |
| デバイス | PC |
| 認証 | 要 |

#### 概要
グリッド上に席をドラッグで自由配置するビジュアルエディタ。保存するとホール席一覧に即時反映される。

#### UI要素

| # | 要素 | 説明 |
|---|---|---|
| 1 | 左パレット | テーブル矩形・席・カウンター席のドラッグ元 |
| 2 | グリッドキャンバス | ドラッグで自由配置。グリッドスナップ |
| 3 | テーブル矩形 | 席を載せる土台。移動すると席も一緒に移動 |
| 4 | 席セル | テーブル上にドロップで紐づく。クリックで編集 |
| 5 | 席編集パネル | 席名変更・削除 |
| 6 | 保存ボタン | ホール席一覧に即時反映 |
| 7 | フッターサマリー | テーブル数・席数の合計表示 |

#### 操作ルール

- 使用中の席は削除不可
- テーブルを移動すると紐づく席も一括移動
- 席をテーブル外にドロップすると紐づき解除

## 5. 共通仕様

### 営業時刻警告バナー

営業終了予定時刻を超過した場合、**全画面のヘッダー**に赤色警告バナーを常駐表示する。

```
🔴 営業終了予定時刻を過ぎています。営業を締めてください。  [締める]
```

- 表示条件: 現在時刻 > 設定した営業終了予定時刻
- 表示画面: S02, S03, S04, S06, S07, S08, S09
- 「締める」ボタンクリック → S01のモード選択画面へ誘導

### モード切替

- ホール画面（S02）右上に「キッチン」ボタン
- キッチン画面（S03）右上に「ホール」ボタン
- クリックで即切替（遷移アニメーションあり）

### レスポンシブ対応（S04）

| 画面幅 | 表示方法 | 主な利用シーン |
|---|---|---|
| スマホ幅（〜767px） | フルスクリーン遷移 | ホール店員がスマホで操作 |
| タブレット幅（768px〜） | サイドパネル | キッチンがタブレットで操作 |

## 6. 注文ステータスフロー

```
[注文作成]
    │
    ▼
 pending（未調理）
    │
    │ 調理完了ボタン（キッチン or ホール）
    ▼
  ready（提供待ち）
    │
    │ 提供完了ボタン（キッチン or ホール）
    ▼
 served（提供済み）

※ pending / ready → × ボタン → cancelled（キャンセル済み）
※ キャンセルは数量指定可（一部キャンセル対応）
```

### ステータス別表示

| ステータス | 色 | 席一覧バッジ | キッチン表示 |
|---|---|---|---|
| pending | オレンジ | 注文件数バッジ | 未調理エリアに表示 |
| ready | 黄 | 🍽 提供待ちバッジ | 提供待ちエリアに表示 |
| served | グレー | — | 非表示 |
| cancelled | 薄グレー | — | 非表示 |
