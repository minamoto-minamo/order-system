# Accounting Notes

## Purpose

会計・売上集計に関する設計上の注意点をまとめる。

## Audience

バックエンド実装者、経理、プロダクトマネージャ

## Key Points

- 金額は整数（最小通貨単位）で保存する（例: JPY は 円、USD は セント）
- 税率は `Setting` テーブル（`taxRateInHouse`, `taxRateTakeout`）に保持し、税額計算はフロントエンドで実施する
- `OrderItem` は `isTakeout` フラグを持ち、内税/外税の区別に使用する
- 日次クロージング（営業締め）処理の仕様を明示する（計算タイミング、集計窓）

## Reporting

- 日次/週次/月次での集計キーを定義（店舗ID, 決済種別, 支払ステータス など）
- 集計は可能なら ETL / バッチで実行し、オンラインクエリ負荷を避ける

## Notes

複雑な会計処理は経理チームと要件を確定してから実装する。
