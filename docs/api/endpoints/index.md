# API Endpoints

リソースごとの REST API エンドポイントグループ一覧。フロント実装者・バックエンド実装者・QA 向け。各詳細ファイルでは request/response の例を JSON で示す。

- [Auth](./auth.md) — ログイン・ログアウト・ログインユーザー取得（E001）
- [Sessions](./sessions.md) — 営業セッションの開始・終了・取得（E002）
- [Groups](./groups.md) — 来店グループの作成・更新・削除（E003）
- [Orders](./orders.md) — 注文の作成・更新・取消（E004）
- [Seats / SeatTables](./seats.md) — 席・テーブル枠の参照・管理（E005）
- [Menus / Categories / SubCategories](./menus.md) — メニュー・カテゴリ・サブカテゴリの参照・管理（E006）
- [Courses](./courses.md) — コース・セットメニュー（E007）
- [Drink Plans](./drink-plans.md) — ドリンクプラン・飲み放題（E008）
- [Staff](./staff.md) — スタッフ管理・デバイスセッション管理（E009）
- [Settings](./settings.md) — 店舗情報・税率・営業時間などの設定（E010）
- [Reports](./reports.md) — セッション単位の売上レポート（E011）
- [Seat Layout](./seat-layout.md) — 席レイアウトの一括取得・保存（E012）
- [Platform](./platform.md) — マルチテナント（店舗）管理（E013）
